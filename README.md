# AutoDash2

AutoDash 차량 영상 제작 흐름을 한국어로 재현한 공개 웹앱입니다. 차량 정보를 입력하고 사진 5장을 골라 9:16 세로 매물 소개 영상을 만듭니다.

## 사용 기능

- 차량 기본 정보와 딜러 로고 입력
- JPG, PNG, WebP 사진 최대 20장 업로드, 영상에 쓸 5장 선택 및 순서 변경
- 10개 영상 스타일 선택과 장면별 문구 편집
- 브라우저에서 미리보기, 영상 생성, 재생 및 다운로드
- 보배드림 사이버매장 링크에서 차량 정보와 사진 가져오기
- 매물 정보는 화면에서 수정하고 사진은 영상 제작 전에 선택·정렬

영상은 Canvas와 MediaRecorder로 기기 내에서 렌더링됩니다. 브라우저 인코더에 따라 MP4 또는 WebM으로 저장되며, 영상은 무음입니다. `목록 링크`는 보배드림 사이버매장 상세 링크를 지원하며, 차량 페이지의 정보와 사진을 불러와 폼에 채웁니다. 다른 사이트 링크는 지원하지 않습니다. 링크 가져오기는 Vercel 서버리스 API를 경유하며, 가져온 사진은 앱에서 저장하지 않습니다. 원본 페이지에서 정보를 읽지 못하는 경우 직접 입력하거나 사진을 업로드할 수 있습니다. AutoDash 원본의 생성형 AI, 음성, 음악, 결제/크레딧 API는 연결하지 않았습니다.
